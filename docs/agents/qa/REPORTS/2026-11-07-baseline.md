## 6. 限制与解释

1. **合成 ≠ FaceTime**：`fr-tcc` 是 1 kHz 自检音，`monitor-mix` 是 440 Hz 合成音，`dual-tone` 是离线 WAV。它们证明采集/封装链路的部分事实，不证明 FaceTime 真人内容。
2. **`monitor-mix` 无麦克风/视频**：因此 MKV 只有 2 条音轨、MP4 只有远端混音；不能据此判定 G3/G4 的“双人 + 视频”完成。
3. **`silentFrames=1` 的旁证**：连续 440 Hz 289792 帧只报 1 个静音帧，和 `TrackRecorder.swift` 中 `frameNonzero` 不复位的逻辑一致；见 DEFECTS QA-001。该字段只影响诊断，不影响 PCM。
4. **时长差**：`fr-tcc.json` 的 host-time duration 与 WAV 样本时长差 10.6 ms；未发现丢帧，暂不作为缺陷，L3 长时测试观察。
5. **监听“可听”未验证**：诊断只证明输出设备是 `BuiltInSpeakerDevice`，没有人工听感记录。
