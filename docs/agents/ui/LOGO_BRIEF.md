# FaceTime Recorder — Logo / App Icon Brief

版本：1.0 · 日期：2026-11-08 · 角色：UI / 视觉 Agent  
用途：品牌标记、App Icon、Dock / Finder / 关于面板 / 文档页眉

---

## 0. 一句话

做一个**安静、原生、可缩到 16 pt 仍认得出来**的 macOS 录音图标：系统蓝圆角方形底、白色声波、珊瑚红录制点，用镜片/通话圆环暗示“面对面对话”，但不使用 FaceTime 商标、Apple 标志或 FaceTime 的绿色摄像机图形。

---

## 1. 品牌属性

| 要 | 不要 |
|---|---|
| 安静、可信、轻量 | 热闹、社交、直播感 |
| macOS 原生工具 | 网页 SaaS、仪表盘 |
| 声音 + 对话 + 录制 | 纯麦克风、纯摄像机、纯波形 |
| 系统蓝 + 白 + 珊瑚红点 | FaceTime 绿、青色、荧光色、多色渐变 |
| 几何、平面、厚形状 | 细线插画、3D 拟物、玻璃高光 |
| 16 pt 仍可辨识 | 依赖文字或细小纹理 |

关键词：`wave`、`lens`、`call`、`record`、`quiet`、`native`。

---

## 2. 法律与商标红线

1. **不使用 FaceTime 商标图形**：不得复刻 FaceTime App 的白色摄像机、绿色渐变圆角方块、镜头光晕或图标构图。
2. **不使用 Apple logo**：不得出现被咬苹果、苹果轮廓、Apple 字体、App Store 风格描边。
3. **不使用系统 SF Symbols 直接作为 Logo**：`waveform`、`video.fill`、`phone.fill` 只能作为设计参考，最终图形必须自绘。
4. **不在图标内放文字**：不放 `FR`、`FaceTime`、`Recorder`、`录音`。文字在 16 pt 下不可读，也会增加商标风险。
5. **不使用 Apple 系统绿**：避免 `#34C759` / `#30D158` 这类 FaceTime 联想色；使用系统蓝 `#007AFF`。
6. **不做“摄像机 + 红点”的直白组合**：容易像相机/直播 App，也容易靠近 FaceTime 图形。圆环 + 波形 + 录制点更安全。
7. **产品名另行审查**：窗口标题暂用 `FaceTime 录音`，但图标本身必须是独立品牌；发布前由总调度/法务确认名称使用边界。
8. **旧青绿稿作废**：不得使用任何青绿/绿色；底板只用系统蓝 `#007AFF`。

## 3. 三个 Logo 方向

三个方向统一使用：系统蓝 `#007AFF` + 白 `#FFFFFF` + 珊瑚红 `#FF6B5E`。不引入青绿、绿色或第三种高饱和色。

### 方向 A — Wave Lens / 声波镜头（推荐）

**概念**：一个圆角方形 App 底板，中央是一枚“镜片/通话圆环”，环内是五段声波，右下角一枚珊瑚红录制点。  
**读法**：声音（波形）+ 面对面对话（镜片/圆环）+ 正在录（红点）。

```text
┌──────────────────────────┐
│                          │
│        ╭────────╮        │
│       │   ▂▅▇▅▂  │       │
│       │          │   ●   │
│        ╰────────╯        │
│                          │
└──────────────────────────┘
```

**优点**

- 三个元素各自清楚，但整体只有一个主轮廓，像系统工具。
- 圆环不是摄像机，也不是 Apple logo；镜片/通话的含义足够含蓄。
- 红点提供“录制”语义，且与 UI 的录制红点同源。
- 缩到 32 pt 仍能读出“波形 + 点”；16 pt 用简化版。

**风险**

- 圆环 + 五段波形在全尺寸略满；16 pt 必须去掉圆环。
- 红点位置要避开波形，避免看成“波形上的球”。

**推荐理由**：最符合“安静、原生、录音工具”，且不靠 FaceTime 图形就能表达“对话中的声音”。

---

### 方向 B — Two Voices / 双声波

**概念**：左右两组声波向中间靠拢，中间留一个负空间圆点；代表“对方”和“我”两个声音源。  
**读法**：两条声音在一个录音点汇合。

```text
┌──────────────────────────┐
│                          │
│      ▂▄▆       ▆▄▂       │
│      ▂▄▆   ●   ▆▄▂       │
│      ▂▄▆       ▆▄▂       │
│                          │
└──────────────────────────┘
```

**优点**

- 直接对应 UI 的两个开关：录对方 / 录我。
- 左右对称，适合做启动图、文档页眉。
- 不需要圆环，形状更抽象、更品牌化。

**风险**

- 容易变成通用均衡器/音频 App，缺少“对话”语义。
- 两组波形在 16 pt 下容易糊成一条纹理。
- 中间红点若太小，会被读成“暂停”或“播放”。

**适用**：如果产品后续强调“双轨 / 两个人”，可作为品牌延展图形，而不是主图标。

---

### 方向 C — Conversation Loop / 对话回环

**概念**：一条连续的回环丝带，形状介于对话气泡与无限符号之间；丝带终点收成一枚录制点。  
**读法**：一段持续进行的对话，被记录成一个闭环。

```text
┌──────────────────────────┐
│                          │
│        ╭──────╮          │
│       ╱        ╲         │
│      │    ●     │        │
│       ╲        ╱         │
│        ╰──────╯          │
│                          │
└──────────────────────────┘
```

**优点**

- 最有“品牌图形”潜力，适合做动效和周边。
- 回环有“保存、归档、完整”的心理暗示。
- 不依赖麦克风/摄像机等陈词滥调。

**风险**

- 细丝带在 16 pt 下会消失；必须做成粗描边或实心负空间。
- 容易像无限符号、结、或某个社交产品，识别不稳定。
- 与“录音”的关联最弱，需要红点补救。

**适用**：品牌成熟后做辅助图形；不建议作为第一版 App Icon。

---

## 4. 推荐

**推荐方向 A：Wave Lens / 声波镜头。**

理由排序：

1. 16 pt 可读性最好：底板、波形、红点三层结构，简化后仍成立。
2. 语义最完整：声音 + 对话 + 录制，不依赖文字。
3. 最像 macOS 工具：厚形状、系统蓝、无细线、无 3D。
4. 法律最安全：没有摄像机、没有绿色渐变、没有 Apple 图形。
5. 与 UI 一致：主色 `#007AFF`、录制红 `#FF3B30`、背景 `#F5F5F7` 可直接复用 token。

## 5. 推荐方案 SVG 级规格

### 5.1 画布与网格

| 项 | 值 |
|---|---|
| 画布 | `1024 × 1024` |
| 图标底板 | `824 × 824`，位于 `(100, 100)` |
| 底板圆角 | `rx = 185`（约 22.5%） |
| 安全边距 | 四周 100；标记不得越过 |
| 基础网格 | 8 px；关键圆/矩形落在 4 px 网格 |
| 视觉中心 | `(512, 512)` |

### 5.2 颜色

| 层 | 颜色 | 说明 |
|---|---|---|
| 底板 | `#007AFF` | 系统蓝，单色平铺，不用渐变 |
| 镜片圆环 | `#FFFFFF`，50% 不透明 | 细白环，不要抢波形 |
| 波形 | `#FFFFFF` | 纯白 |
| 录制点 | `#FF6B5E` | 珊瑚红，与 UI 录制红 `#FF3B30` 区分 |
| 录制点外环 | `#FFFFFF` | 16 px 宽，负责与底板分离 |

不使用第三种高饱和色；不使用多彩渐变。

### 5.3 几何

| 元素 | 几何 |
|---|---|
| 底板 | `rect x=100 y=100 w=824 h=824 rx=185` |
| 镜片圆环 | `circle cx=512 cy=512 r=246`，`fill=none`，`stroke=#FFFFFF`，`stroke-opacity=.50`，`stroke-width=20` |
| 波形 | 5 个圆角竖条，宽 54，间距 38，圆角 27 |
| 波形高度 | 96 / 208 / 312 / 208 / 96 |
| 波形 x | 301 / 393 / 485 / 577 / 669 |
| 波形 y | 464 / 408 / 356 / 408 / 464 |
| 录制点 | `circle cx=708 cy=708 r=64`，`fill=#FF6B5E`，`stroke=#FFFFFF`，`stroke-width=16` |

说明：

- 五条波形的总宽为 `5×54 + 4×38 = 422`，从 x=301 到 x=723，中心正好 512。
- 中间波形高 312，位于镜片环内；两端波形只到 96，形成自然的“说话/声波”轮廓。
- 录制点圆心在 `(708, 708)`，落在圆环 4:30 方向外侧，与外环相交；白色描边把它从底板和圆环中“切”出来。
- 圆环内缘半径 236，波形总宽 422，左右各留约 25 px；圆环不要压到波形。

### 5.4 可直接使用的 SVG 母版

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1024 1024">
  <rect x="100" y="100" width="824" height="824" rx="185" fill="#007AFF"/>

  <circle cx="512" cy="512" r="246"
          fill="none" stroke="#FFFFFF" stroke-opacity="0.50"
          stroke-width="20"/>

  <g fill="#FFFFFF">
    <rect x="301" y="464" width="54" height="96"  rx="27"/>
    <rect x="393" y="408" width="54" height="208" rx="27"/>
    <rect x="485" y="356" width="54" height="312" rx="27"/>
    <rect x="577" y="408" width="54" height="208" rx="27"/>
    <rect x="669" y="464" width="54" height="96"  rx="27"/>
  </g>

  <circle cx="708" cy="708" r="64"
          fill="#FF6B5E" stroke="#FFFFFF" stroke-width="16"/>
</svg>
```

该 SVG 为平面母版，不带投影。导出 App Icon 时可在外围加极轻投影，但投影不得烘焙进 Logo 本体。

### 5.5 小尺寸简化

App Icon 必须准备 16 / 32 / 64 / 128 / 256 / 512 / 1024 px 导出。16 / 32 px 使用简化规则：

| 元素 | 16 px | 32 px | 64 px 以上 |
|---|---|---|---|
| 底板 | 保留 | 保留 | 保留 |
| 圆环 | 删除 | 删除或 1 px 极淡环 | 保留 |
| 波形 | 3 条，2 / 6 / 2 px | 3 条，4 / 11 / 4 px | 5 条 |
| 录制点 | 2 px 点 | 3 px 点 | 完整 64/1024 比例 |
| 白色描边 | 不加 | 1 px | 16/1024 比例 |

16 px 不追求“完整细节”，追求“像录音按钮”的剪影：三条短竖线 + 一个珊瑚点。

### 5.6 光学修正

- 波形整体可向左移 4 px，抵消右下红点的视觉重量；母版先按几何居中，导出前做 2–4 px 光学校正。
- 红点不要比中间波形更宽；在 16 px 下红点直径不超过 3 px。
- 圆环透明度不要低于 45%，否则在浅色 Dock 背景上会消失。
- 底板保持系统蓝单色，不使用渐变；让白色波形成为主体。

### 5.7 单色 / 反白 / 模板版

| 版本 | 规则 |
|---|---|
| 单色黑 | 去掉系统蓝底板，用 `#1D1D1F` 实心底板；波形/圆环用白；红点改为白或镂空 |
| 单色白 | 透明底，全部元素用 `#FFFFFF`；红点改为镂空圆 |
| 模板版 | 纯 alpha 剪影：底板 + 波形 + 点都并成一个形状，用于菜单栏/工具栏 |
| 深色版 | 底板 `#0066CC`；波形 `#FFFFFF`；红点 `#FF7A70` |

模板版不用于 Dock 主图标，只用于系统内的单色场景。

## 6. App Icon 适配

### 6.1 macOS 图标网格

- 1024 × 1024 画布，透明背景。
- 底板 824 × 824 居中，四周 100 px 透明边距。
- 圆角 185 px，对应 macOS Big Sur 之后的连续圆角网格。
- 不铺满画布；不要做 iOS 那种满幅圆角。
- 允许在底板外做 `0 12 30 rgba(16,24,40,0.18)` 的轻投影，但只用于最终 PNG/ICNS，不写进 SVG 母版。
- 图标内不放文字、不放版本号、不放“录音中”状态。

### 6.2 导出清单

```text
AppIcon.iconset/
  icon_16x16.png
  icon_16x16@2x.png     32
  icon_32x32.png        32
  icon_32x32@2x.png     64
  icon_128x128.png      128
  icon_128x128@2x.png   256
  icon_256x256.png      256
  icon_256x256@2x.png   512
  icon_512x512.png      512
  icon_512x512@2x.png   1024
```

最终生成 `AppIcon.icns`；同时保留 1024 PNG 用于文档、关于面板和商店页。

### 6.3 Dock / Finder / 关于面板

| 场景 | 规则 |
|---|---|
| Dock | 用完整彩色版；不自动切换深色，除非系统启用 tinted 图标 |
| Finder | 完整彩色版；文件名旁边不叠加红点 |
| 关于面板 | 64–128 px；可用深色/浅色两版 |
| 菜单栏 | 如未来需要，使用模板版，不使用彩色图标 |
| 文档页眉 | 可用 24–32 px 彩色版；旁边可配 `FaceTime 录音` 文字，但文字不属于 Logo |

### 6.4 背景与对比

- 底板主色 `#007AFF` 在浅色 Dock 上对比足够；不要在图标外再加浅色描边。
- 不把图标放在纯白卡片上做“展示底板”；透明边距就是它的呼吸区。
- 如果系统启用 tinted icon，提供单色模板；不要让系统自动给底板改色。

## 7. 使用规范

### 7.1 最小尺寸

- 彩色完整版：≥ 32 px。
- 16 px：使用简化版，不直接缩放完整版。
- 单色模板：≥ 16 px。

### 7.2 留白

- 图标外部 clear space：至少 `0.25 × 底板宽`（约 208 px @1024）。
- Logo 与文字并排时，图形与文字间距 ≥ 图标宽度的 0.25。
- 不在 Logo 外加圆形/方形底色；底板已经是容器。

### 7.3 禁止

- 不旋转、不倾斜、不加透视。
- 不改变波形数量（完整版固定 5 条；小尺寸固定 3 条）。
- 不把红点改成绿色或渐变。
- 不加摄像机镜头、播放三角、暂停双竖线、FaceTime 摄像机。
- 不加 Apple logo、系统 SF Symbol、App Store 边框。
- 不用文字、字母、汉字代替图形。
- 不做 3D 高光、玻璃、内发光、彩色投影。
- 不把底板做成 FaceTime 绿或系统蓝。

## 8. 验收清单

- [ ] 1024 px 下，底板 824、圆角 185、四周 100 透明边距。
- [ ] 圆环、五段波形、珊瑚红点三层关系清楚。
- [ ] 缩到 32 px 仍能读出“波形 + 红点”。
- [ ] 16 px 简化版只有三条波形 + 一个点，不糊。
- [ ] 没有 FaceTime 摄像机、Apple logo、系统绿色、文字。
- [ ] 浅色 Dock / 深色 Dock 都不需要额外描边。
- [ ] 单色模板可用；深色版不刺眼。
- [ ] `.icns` 各尺寸齐全，无拉伸、无错位。
- [ ] 图标与 UI 主色 `#007AFF`、录制红 `#FF3B30` 同源但不完全相同（图标红点为珊瑚红）。
