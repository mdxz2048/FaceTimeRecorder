# FaceTime Recorder — 极简 UI 规范

版本：2.0 · 日期：2026-11-07 · 角色：UI Agent

状态：**极简版设计稿；FaceTime 远端音频仍为“待真人通话验证”。**

---

## 0. 决策与边界

### 0.1 用户原话

> “界面简单一点，不要这么复杂，只要选择是不是录对方的声音或者录麦克风的声音就完了。”

本规范以此为准，覆盖旧版 UI_SPEC 的复杂布局。

### 0.2 一句话界面

一个 520×420 的单屏窗口：

- 标题：`FaceTime 录音`
- 说明：`画面 + 声音，一次录好`
- 两个大开关：`录制对方声音`、`录制我的麦克风`
- 一个全宽主按钮：`开始录制` / `停止并保存`
- 一行状态 + 计时
- 完成后一行：`已保存 FaceTime.mp4（双方声音）` + `在 Finder 中显示`
- 常驻小字：`请确保通话对方同意录音。`
- 底部小字：`远端音频：待真人通话验证`
- 最底部极小的 `高级` DisclosureGroup，默认收起。

### 0.3 Non-goals

- 不做侧栏、卡片墙、仪表盘、A/B/C 三区。
- 不在主界面显示 FFmpeg、8ch、tap、aggregate、OSStatus、路由、权限矩阵。
- 不在主界面显示“系统输出未指向”“虚拟声卡已接管”等技术横幅。
- 不做多窗口、设置窗口、标签页。
- 不写 Swift 代码、不改 Core。
- 不声称“已支持 FaceTime 音频”或“已验证”。

### 0.4 产品红线：监听不可选

**监听是内部固定通路，不是用户设置。**

- 不提供监听输出选择器。
- 不提供监听音量滑杆。
- 不提供“跟随系统输出”“内置扬声器/耳机”等选项。
- 高级里也不放选择器，只放一行只读文字：
  `声音播放：MacBook Pro 扬声器（系统音量控制）`
- 对方声音始终送到**接管前的那台物理输出设备**；音量由 macOS 系统音量控制。
- 如果接管前系统输出不是物理设备，回退到内置扬声器，并在只读行显示实际设备名。
- 任何人不得把监听选择/音量加回界面；这是产品红线。

## 1. 窗口

| 项 | 值 |
|---|---|
| 默认尺寸 | **520 × 420 pt**（含标题栏） |
| 最小尺寸 | **500 × 400 pt** |
| 最大宽度 | 640 pt；单列，不拉成宽屏 |
| 布局 | 单列 `VStack`，无侧栏、无网格、无卡片墙 |
| 标题栏 | macOS 标准标题栏；标题 `FaceTime 录音` |
| 背景 | 窗口背景色；内容区不加整块卡片底 |
| 内容边距 | 左右 24 pt，上下 20 pt |
| 可缩放 | 可纵向放大；高级展开时允许窗口增高到 640 pt，超过后高级区内部滚动 |
| 多开 | 禁止 |

主内容从上到下：

```
标题 / 说明
两个大开关
主按钮
状态行
结果行（完成后出现）
同意录音小字
待验证小字
高级 DisclosureGroup
```

没有顶部徽章，没有工具栏按钮，没有右侧状态栏。

## 2. 主界面控件

### 2.1 标题区

| 元素 | 规格 |
|---|---|
| 标题 | `FaceTime 录音`，24 pt semibold，主文字色 |
| 说明 | `画面 + 声音，一次录好`，13 pt regular，次要文字色 |
| 间距 | 标题与说明 4 pt；标题区与开关 20 pt |

标题区左对齐，不居中。不要加副标题、版本号、帮助按钮。

### 2.2 两个大开关

两个开关占满整行，整行可点，不是小 checkbox。

#### 开关一：录制对方声音

| 项 | 内容 |
|---|---|
| 图标 | `speaker.wave.2.fill`，22 pt |
| 标题 | `录制对方声音`，15 pt semibold |
| 副文案 | `通过 HomePod Flow 虚拟声卡`，12 pt 次要文字 |
| 默认 | 开 |
| 映射 | 开：录制远端音频；关：不录远端，也不接管系统输出 |

#### 开关二：录制我的麦克风

| 项 | 内容 |
|---|---|
| 图标 | `mic.fill`，22 pt |
| 标题 | `录制我的麦克风`，15 pt semibold |
| 副文案 | `使用 Mac 默认麦克风`，12 pt 次要文字 |
| 默认 | 开 |
| 映射 | 开：录制麦克风；关：不录麦克风 |

#### 行的外观

- 高度 **64 pt**，左右内边距 16 pt。
- 背景：`bg.row`；圆角 10 pt；1 px 边框。
- 行内 `HStack`：图标 + `VStack`（标题/副文案）+ `Spacer` + 开关。
- 整行 `contentShape(Rectangle())`；点标题、副文案、空白处都能切换。
- 开关只作为状态指示；点击行任意位置都切换。
- 整行只放一个可点击元素；右侧开关不要做成第二个独立 `Toggle`，否则会双触发。
- 关闭时整行不降低到不可读；标题仍为主文字色，副文案仍可读。
- 两行间距 8 pt。

#### 两个都关

- 主按钮禁用。
- 状态行显示：`至少选择一种声音`。
- 不弹窗、不警告横幅。

### 2.3 主按钮

| 状态 | 文案 | 外观 |
|---|---|---|
| idle | `开始录制` | 全宽、50 pt 高、红色填充、白字、圆角 10 |
| preparing | `正在准备…` | 同上，降饱和，禁用 |
| recording | `停止并保存` | 全宽、红色填充、白字 |
| stopping | `正在保存…` | 禁用，显示 spinner |
| finished | `开始录制` | 红色填充，准备下一次 |
| failed | `重试` | 红色填充 |

- 按钮宽度 = 内容宽度，左右不留额外边距。
- 字号 15 pt semibold。
- 按钮上方 18 pt，下方 12 pt。
- 不显示“取消”。没有取消 API。
- 不在按钮下方堆一排小按钮。

### 2.4 状态行 + 计时

一行 `HStack`：

```
● 录制中                                      00:03:42
```

| 状态 | 左侧 | 右侧 |
|---|---|---|
| idle | `就绪` | 不显示时间 |
| preparing | `正在准备…` + 小 spinner | 不显示时间 |
| recording | 红点 + `录制中` | `00:03:42`，等宽数字 |
| stopping | `正在保存…` | 冻结时间 |
| finished | `已完成` | 最终时长 |
| failed | 一句人话错误 | 不显示时间 |

- 状态行 12 pt；计时 13 pt 等宽数字。
- 录制红点 8 pt，静态；不做脉冲。
- 状态行不显示“FaceTime 已连接”“远端正常”。
- 失败时状态行可以换成错误句，最多两行；不再额外显示横幅。

### 2.5 结果行

仅在 `finished` 出现，一行：

```
已保存 FaceTime.mp4（双方声音）          在 Finder 中显示
```

| 情况 | 文案 |
|---|---|
| 远端 + 麦克风 | `已保存 FaceTime.mp4（双方声音）` |
| 只有远端 | `已保存 FaceTime.mp4（对方声音）` |
| 只有麦克风 | `已保存 FaceTime.mp4（我的声音）` |
| MP4 未生成 | `已保存原始文件，但 MP4 生成失败` + `查看高级` |

规则：

- 结果行 13 pt；文件名可用中等字重。
- `在 Finder 中显示` 是文字链接/小按钮，不抢主按钮。
- 不显示 MP4/MKV 两张文件卡；不显示文件大小、轨道数、封装命令。
- MKV 归档只在高级里显示路径，不在主界面出现。
- 结果行不自动打开 Finder、不自动播放。
- 如果对应音轨全零，结果行改为 `已保存 FaceTime.mp4（未检测到声音）`，不写“双方/对方/我的”。

### 2.6 常驻声明

在结果行下方：

- `请确保通话对方同意录音。`，11 pt，次要文字色。
- 始终显示，不因状态隐藏。

再下方一行：

- `远端音频：待真人通话验证`，11 pt，三级文字色。
- 只做一行小字，不做徽章、不做图标、不做背景色。
- 只有总调度在 G1 真人通话验收后，才可改为 `远端音频：已验证`；UI 不提供切换开关。

### 2.7 高级 DisclosureGroup

- 位于最底部，标签 `高级`，11 pt，默认收起。
- 收起时只占一行，不加边框、不加背景。
- 展开后显示紧凑设置；不改变主界面结构。
- 展开区内部 12 pt 字号，行高 24—28 pt，不使用卡片。
- 高级内容见 §4。

## 3. 状态与文案

### 3.1 状态机

| 状态 | 主界面表现 | 主按钮 |
|---|---|---|
| idle | `就绪`；两个开关可用 | `开始录制` |
| preparing | `正在准备…` + spinner；开关禁用 | `正在准备…` |
| recording | 红点 + `录制中` + 计时；开关禁用 | `停止并保存` |
| stopping | `正在保存…`；计时冻结 | `正在保存…` |
| finished | `已完成`；结果行出现 | `开始录制` |
| failed | 一句人话；开关可用 | `重试` |

### 3.2 状态文案

| 情况 | 文案 |
|---|---|
| 就绪 | `就绪` |
| 准备 | `正在准备…` |
| 录制 | `录制中` |
| 保存 | `正在保存…` |
| 完成 | `已完成` |
| 两个开关都关 | `至少选择一种声音` |
| 麦克风权限缺失 | `没有麦克风权限。请在系统设置中允许，或关闭“录制我的麦克风”。` |
| 屏幕录制权限缺失 | `没有屏幕录制权限。请在系统设置中允许后重新开始。` |
| 没听到对方 | `没有听到对方的声音。请确认 FaceTime 正在通话，并允许系统音频录制。` |
| 找不到虚拟声卡 | `没有找到 HomePod Flow 虚拟声卡。请确认它已安装。` |
| MP4 失败 | `已保存原始文件，但 MP4 生成失败。请查看高级 → 诊断。` |
| 保存失败 | `无法保存文件。请检查磁盘空间后重试。` |
| 通用失败 | `录制没有开始。请重试；仍失败请查看高级 → 诊断。` |

规则：

- 失败只显示一句人话，不出现 OSStatus、FFmpeg、8ch、tap、aggregate、路由术语。
- 需要用户操作时，句子里直接说“在系统设置中允许”或“关闭麦克风开关”；不弹出额外对话框。
- 不在主界面显示“系统输出未指向”之类警告；路由由 App 自动处理。

### 3.3 录制中允许/禁止

允许：

- `停止并保存`
- `高级` 展开查看（只读）
- 窗口缩放

禁止：

- 两个声音开关
- 任何设备选择
- AEC、诊断中的“重新自检”
- 关闭窗口/⌘Q 需确认；提示 `停止并保存后退出？`

## 4. 高级内容

高级是“设置抽屉”，不是第二个仪表盘。只放必要项，紧凑排列。

```
v 高级
  远端设备        [HomePod Flow Audio        v]
  麦克风          [MacBook Pro 麦克风        v]
  [ON] Apple 回声消除（实验性）
  权限  麦克风 ✓   屏幕录制 ✓   系统音频 由自检确认
  声音播放：MacBook Pro 扬声器（系统音量控制）
  画面：FaceTime 窗口
  开始录制时会把系统声音切到 HomePod Flow，停止后自动恢复。
  [重新自检]  [打开诊断]  [查看日志]
```

### 4.1 高级里保留的控件

| 控件 | 说明 |
|---|---|
| 远端设备 | 虚拟声卡选择；默认 HomePod Flow；只在高级出现 |
| 麦克风 | 输入设备选择；默认 Mac 默认麦克风 |
| Apple 回声消除 | 默认开；标注“实验性、待真人验证” |
| 权限详情 | 麦克风、屏幕录制、系统音频；系统音频只能写“由自检确认” |
| 声音播放 | **只读文字**：`声音播放：<实际设备>（系统音量控制）`；不可选择、不可调音量 |
| 画面 | **只读状态**：`画面：FaceTime 窗口` 或 `画面：主显示器（未找到 FaceTime 窗口）`；不列窗口、不提供选择 |
| 路由说明 | **只读一行**：`开始录制时会把系统声音切到 HomePod Flow，停止后自动恢复。` |
| 重新自检 | 只在 idle/finished/failed 可用；录制中禁用 |
| 打开诊断 | 只读诊断 sheet |
| 查看日志 | 最近事件，最多 200 条 |

### 4.2 高级里删除的东西

- 系统输出接管开关：删除，改为自动。
- 监听输出选择器：删除；监听不可选。
- 监听音量滑杆：删除；用 macOS 系统音量控制。
- 画面源选择器/窗口列表：删除；V1 只录 FaceTime 窗口，找不到才回退主显示器。
- 录屏开关：删除，画面始终录制。
- 自检按钮（主界面）：删除，改为开始前自动自检。
- 保存位置选择：删除，固定 `~/Movies/FaceTime Recorder`；高级可显示路径但不可改。
- 多轨归档卡片：删除，高级只显示 `FaceTime.mkv` 路径（存在时）。
- FFmpeg、8ch、tap、aggregate、采样率、声道布局：删除，诊断里才出现。
- 权限大横幅、路由大横幅、设备断开大横幅：删除，状态行一句话。

### 4.3 高级的展开行为

- 默认收起，只显示 `高级` 一行。
- 展开后窗口允许增高到 640 pt；超过后高级区内部滚动。
- 收起后回到 520×420。
- 不使用 sheet/popover；保持单屏。

## 5. 自动处理

以下全部由 App 自动完成，主界面不暴露开关：

| 行为 | 规则 |
|---|---|
| 系统输出接管 | `录制对方声音` 开启时，开始前自动把系统默认输出切到虚拟声卡；停止、退出、下次启动恢复 |
| 监听 | 内部固定通路：对方声音送到**接管前的那台物理输出设备**；音量用 macOS 系统音量控制 |
| AEC | 麦克风开启时默认 Apple 语音处理；高级可关 |
| 自检 | 每次开始前自动做 1 秒非静音自检；失败则一句人话 |
| 画面目标 | V1 只录 FaceTime 窗口；启动时自动查找；找不到才回退主显示器；不列窗口、不弹选择器 |
| 视频 | 始终录制画面；不在主界面给开关 |
| 麦克风 | 默认 Mac 默认麦克风；高级可换 |
| 权限 | 开始录制时按需触发系统授权弹窗；不自动点击、不绕过 |
| MP4 | 自动把远端+麦克风混音进 `FaceTime.mp4`；MKV 作为高级里的归档 |
| 错误路由 | 自动判断权限/设备/自检/保存，主界面只显示一句结论 |

**Core 缺口：** 当前 `RecorderConfiguration` 没有 `recordRemote` 字段，`RecorderEngine.start` 总是启动远端 tap 和远端音轨。Dev 必须补“是否录制对方声音”的配置；否则关闭第一个开关无法真正停止远端采集/接管。

不自动做：

- 不自动开始录制。
- 不自动打开 Finder。
- 不自动播放。
- 不自动拨号。
- 不自动点击权限弹窗。
- 不自动切换用户已选的设备（除首次默认）。

## 6. 直接删除的控件/元素

以下从旧版主界面删除，不再出现：

1. 顶部 `远端音频：待验证` 大徽章 → 改为底部一行小字。
2. 设备与权限卡片、录制控制卡片、状态/电平/日志侧栏。
3. 远端设备、麦克风两个主界面选择器 → 移入高级。
4. 监听输出选择器 → **彻底删除**；高级里只保留只读 `声音播放：…`。
5. 监听开关、监听音量滑杆 → **彻底删除**；固定内部通路，音量用 macOS 系统音量。
6. AEC 主界面开关 → 移入高级。
7. 录屏开关、画面源选择器、窗口列表、刷新按钮 → 删除；V1 只录 FaceTime 窗口，找不到才回退主显示器。
8. 系统默认输出接管开关 → 删除；自动。
9. 自检按钮 → 删除；自动。
10. 保存位置与“更改…” → 删除；固定路径。
11. 电平表、峰值、回调数、监听缓冲、健康行 → 删除；诊断里才有。
12. 日志面板 → 移入高级。
13. 诊断按钮/卡片 → 移入高级。
14. MP4/MKV 两张结果卡 → 主界面只留一行结果；MKV 路径在高级。
15. FFmpeg、8ch、tap、aggregate、OSStatus、路由、权限矩阵等技术徽章/横幅 → 全部删除。
16. “系统输出未指向虚拟声卡”“接管开启但监听关闭”等警告 → 删除；自动处理，失败才一句话。
17. 关闭确认里的技术说明 → 只保留“停止并保存后退出？”。

## 7. 视觉规范

### 7.1 风格

- macOS 原生、干净、安静；像一个简单的录音按钮，不像控制台。
- 单列、左对齐；大量留白；不使用卡片墙。
- 两个开关行是唯一的“块”；不加阴影、不加渐变。
- 红色只用于主按钮和录制红点；绿色只用于完成/权限通过；橙色只在高级里表达警告。
- 深色/浅色同一布局，不靠颜色区分状态。

### 7.2 颜色 token

优先使用系统语义色：`labelColor`、`secondaryLabelColor`、`tertiaryLabelColor`、`separatorColor`、`windowBackgroundColor`、`controlBackgroundColor`。

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `bg.window` | `#F5F5F7` | `#1C1C1E` | 窗口背景 |
| `bg.row` | `#FFFFFF` | `#2C2C2E` | 两个开关行 |
| `bg.rowHover` | `#F0F0F4` | `#333336` | 行悬停 |
| `border.row` | `#D9D9DE` | `#3A3A3C` | 行边框 |

## 8. 可访问性

### 8.1 键盘

| 操作 | 快捷键 |
|---|---|
| 开始/停止 | `⌘R` |
| 切换两个开关 | `Tab` 聚焦后 `Space` |
| 展开/收起高级 | `Tab` 聚焦后 `Space` |
| 关闭窗口 | `⌘W`；录制中弹确认 |
| 退出 | `⌘Q`；录制中弹确认 |

焦点顺序：`录制对方声音` → `录制我的麦克风` → `开始录制` → `在 Finder 中显示`（完成时）→ `高级` → 高级内控件。

### 8.2 VoiceOver

| 控件 | label | value | hint |
|---|---|---|---|
| 对方声音开关 | `录制对方声音` | 开/关 | `通过 HomePod Flow 虚拟声卡录制对方` |
| 麦克风开关 | `录制我的麦克风` | 开/关 | `使用 Mac 默认麦克风` |
| 主按钮 | `开始录制` / `停止并保存` | — | `录制画面和所选声音` |
| 状态 | `状态` | `录制中` / `就绪` | — |
| 计时 | `录制时长` | `00:03:42` | — |
| 结果 | `保存结果` | `已保存 FaceTime.mp4（双方声音）` | — |
| Finder | `在 Finder 中显示` | — | `打开保存文件夹` |
| 高级 | `高级` | 展开/收起 | `设备、权限、诊断和日志` |

补充：

- 整行是一个可切换元素，VoiceOver 读“开关”角色；不要拆成标题和开关两个焦点。
- 状态变化播报一次：`录制已开始`、`正在保存`、`已保存`、`录制失败：<一句话>`。
- 计时每 10 秒最多更新一次 accessibilityValue；视觉可每秒更新。
- 失败句自动获得焦点；用户可直接重试或打开高级。

### 8.3 对比度/动效

- 正文 ≥ 4.5:1；大字号 ≥ 3:1；控件边界 ≥ 3:1。
- 状态不能只靠颜色：录制有红点 + “录制中”；完成有文字。
- `Reduce Motion` 时关闭非必要过渡；录制红点静态。
- 不使用循环脉冲、跳动电平、闪烁警告。

## 9. 文案规则

### 9.1 必须保留

- `请确保通话对方同意录音。`
- `远端音频：待真人通话验证`（G1 前）
- `通过 HomePod Flow 虚拟声卡`
- `使用 Mac 默认麦克风`
- `声音播放：<设备名>（系统音量控制）`
- `画面：FaceTime 窗口` / `画面：主显示器（未找到 FaceTime 窗口）`
- `开始录制时会把系统声音切到 HomePod Flow，停止后自动恢复。`

### 9.2 禁止出现

- `已支持 FaceTime`
- `远端声音正常`
- `权限已全部授予`
- `FFmpeg`、`8ch`、`tap`、`aggregate`、`OSStatus`、`-10875`
- `系统输出未指向虚拟声卡`
- `虚拟声卡已接管`
- `监听缓冲`、`回调数`、`欠载`
- `选择监听输出`、`监听音量`、`窗口列表`、`显示器选择`（作为控件/选项时）
- `100%`、`保证`、`完美`

### 9.3 失败文案

- 一句人话，最多两行。
- 说“发生了什么 + 下一步”，不说内部术语。
- 需要操作时直接给动作：`在系统设置中允许`、`关闭“录制我的麦克风”`、`查看高级 → 诊断`。
- 不甩 OSStatus，不显示错误编号；错误编号只在高级诊断里。

## 11. 与旧版的关系

- 本文件完全替代旧版 `UI_SPEC.md` 的复杂三区布局。
- 旧版的 MP4/MKV 结果卡、监听状态行、监听输出选择/音量、画面源选择/窗口列表、权限矩阵、路由横幅、电平表全部不进入主界面。
- 旧版中仍然有效的底层事实继续保留：
  - FaceTime 远端音频未真人验证前只能写“待真人通话验证”。
  - 系统音频权限不能预先查询，只能由自检结果推导。
  - 自检通过不等于 FaceTime 已验证。
  - 不得自动点击权限弹窗，不得绕过系统授权。
  - MP4 主文件必须真实存在才能写 `已保存 FaceTime.mp4`；否则显示 MP4 失败一句话。
