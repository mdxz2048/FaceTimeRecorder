# FaceTime Recorder — UI V2（小工具版）

版本：3.1 · 日期：2026-11-08 · 角色：UI / 视觉 Agent  
状态：**覆盖上一版 560 × 480 大窗口方案；待 Dev 实现。**

---

## 0. 方向

这是一个放在桌面角落的小工具，不是仪表盘。

- 默认窗口 **380 × 300**，可宽 360–420，高度固定 300。
- macOS 原生态浅色：`#F5F5F7` 背景、白色卡片、系统灰分隔线。
- 主色只用 **系统蓝 `#007AFF`**；录制态只用 **系统红 `#FF3B30`**。
- 不使用青绿、不使用绿色成功态、不使用大面积色块。
- 主界面只有：小标题、两个紧凑开关、一个 36 pt 主按钮、一行状态/计时、完成时一行结果。
- 没有“高级”折叠，没有设备/窗口/权限选择器。
- 右上角只有一个不显眼的 `…` 菜单：诊断 / 权限 / 关于。

### 0.1 一句话

`两个开关，一个按钮；录完只在按钮下面多一行“已保存”。`

### 0.2 Non-goals

- 不做 560 × 480 大窗口，不做大标题、大卡片、大按钮。
- 不做青绿/绿色主题，不做渐变背景、玻璃、发光、仪表盘。
- 不做“高级”折叠，不把设备、窗口、权限、日志放进主界面。
- 不显示 FFmpeg、8ch、tap、aggregate、OSStatus、采样率、轨道数。
- 不显示第二归档文件，不在 UI 提及其他封装格式。
- 不写 Swift / Core。

### 2.3 对比度

| 组合 | 对比度 | 备注 |
|---|---:|---|
| `text.primary` / `bg.window` | 15.46:1 | AAA |
| `text.secondary` / `bg.window` | 4.66:1 | AA |
| 白字 / `accent` `#007AFF` | 4.02:1 | Apple 系统蓝原生观感；Increase Contrast 时改用 `#0066CC`（5.57:1） |
| `accentText` `#0066CC` / 白 | 5.57:1 | 链接文字优先用这个 |
| `errorText` `#D70015` / `#F5F5F7` | 4.94:1 | AA |

规则：

- 正文不小于 4.5:1；系统蓝按钮在白字下按 Apple 原生观感使用，Increase Contrast 时自动加深。
- 12 pt 及以下文字使用 `text.secondary` 或更深；不使用 `#8E8E93` 作为正文。
- 录制红只用于点、停止按钮、失败文字；不作为大面积背景。

## 3. 组件

### 3.1 标题栏 + `…` 菜单

```text
● ● ●   FaceTime 录音                         ⋯
```

| 项 | 规格 |
|---|---|
| 标题栏高 | 28 pt |
| 标题 | 18 pt semibold，`#1D1D1F`，左对齐，x=76 |
| 说明 | 11 pt regular，`#6E6E73`，位于内容区 y=16 |
| `…` 按钮 | 22 × 22，`ellipsis` 13 pt，`#8E8E93`；hover 底 `#E9E9ED`，圆角 6 |

菜单行为：

- `诊断`：打开诊断文件夹；不显示日志面板。
- `权限…`：打开系统设置对应隐私页；不做权限选择器，不显示权限矩阵。
- `关于`：版本号、版权、`请确保对方同意录音。` 一句说明。

`…` 默认不显眼，不抢主按钮；不使用红色、不使用徽章。

### 3.4 状态行与计时

```text
● 录制中                              00:03:42
```

| 状态 | 左侧 | 右侧 |
|---|---|---|
| idle | 6 pt 空心圆 `#C7C7CC` + `就绪` secondary | 无 |
| preparing | 9 pt spinner + `正在准备…` secondary | 无 |
| recording | 7 pt 实心圆 `#FF3B30` + `录制中` primary | `00:03:42` |
| stopping | 9 pt spinner + `正在保存…` secondary | 冻结时间 |
| finished | `已完成` secondary / 蓝色小字，不加绿色勾 | 最终时长 |
| failed | 一句人话，`#D70015`，最多两行 | 无 |
| 两个都关 | `至少打开一个声音来源`，`#C93400` | 无 |
| 权限缺失 | `需要麦克风权限` / `需要屏幕录制权限`，`#C93400` | 无 |
| 无 FaceTime 窗口 | `没有找到 FaceTime 窗口`，`#C93400` | 无 |

计时规则：

- 默认 `MM:SS`；超过 1 小时自动变 `H:MM:SS`。
- 12 pt monospacedDigit，右对齐，固定宽度约 52 pt（长格式 64 pt）。
- 录制中每秒更新；保存中冻结；完成使用最终时长。
- 失败不显示计时。

失败行：

- 最多两行，12/16，`#D70015`。
- 不显示错误码、OSStatus、设备名。
- 失败后主按钮 `重试`；右下不加大块“错误详情”。

| 链接 | `在 Finder 中显示` 11.5/16 medium，`#0066CC` |
| 图标 | 不加绿色大勾；状态行只写 `已完成` |

文案：

| 条件 | 结果 |
|---|---|

## 4. 状态

| 状态 | 状态行 | 主按钮 | 开关 |
|---|---|---|---|
| idle | `就绪` | `开始录制` | 可用 |
| preparing | `正在准备…` + spinner | `正在准备…` 禁用 | 禁用 |
| recording | 红点 + `录制中` + 计时 | `停止并保存` 红色 | 禁用 |
| stopping | `正在保存…` + spinner，计时冻结 | `正在保存…` 禁用 | 禁用 |
| finished | `已完成` + 最终时长 | `开始录制` | 可用 |
| failed | 一句红字 | `重试` | 可用 |

### 4.1 权限

- 不显示权限列表、权限选择器、权限矩阵。
- 点击 `开始录制` 时按需触发系统权限弹窗；不自动点击、不绕过。
- 权限被拒绝时，只在状态行说一句：
  - `需要麦克风权限`
  - `需要屏幕录制权限`
- 用户可从右上角 `…` → `权限…` 打开系统设置；主界面不加“打开设置”大按钮。
- 系统音频权限不预检；开始时的自检/失败用一句人话表达。

### 4.2 无 FaceTime 窗口

- 不显示窗口选择器，不显示窗口列表。
- App 自动查找 FaceTime 窗口；能回退时静默回退，不打扰用户。
- 无法开始时，状态行一行：`没有找到 FaceTime 窗口`；主按钮 `重试`。
- 不在主界面显示窗口名、窗口数量、屏幕分辨率。

### 4.3 两个都关

- 主按钮灰色禁用。
- 状态行 `至少打开一个声音来源`，`#C93400`。
- 不弹窗、不抖动、不把开关标红。

### 4.4 完成与 MP4 三音轨

UI 只说 `FaceTime.mp4`，不展示音轨数量、轨道名、第二归档文件。

媒体结果为固定三音轨：

1. **Mix**：默认播放轨。
2. **Remote**：非默认轨。
3. **Mic**：非默认轨。

UI 不提供轨道切换；播放器默认听到 Mix。结果文案只按声音来源写“双方 / 对方 / 我的 / 未检测到声音”。

## 6. 可访问性

### 6.1 键盘

| 操作 | 方式 |
|---|---|
| 切换开关 | `Tab` 聚焦整行，`Space` 切换 |
| 开始 / 停止 | `⌘R` |
| 主按钮 | `Return` |
| 打开 `…` 菜单 | `Tab` 到菜单，`Space` / `Return` |
| 关闭窗口 | `⌘W`；录制中确认 `停止并保存后退出？` |

焦点顺序：`录制对方声音` → `录制我的声音` → `开始录制` / `停止并保存` → `在 Finder 中显示`（完成时） → `…` 菜单。

### 6.2 VoiceOver

| 控件 | Label | Value | Hint |
|---|---|---|---|
| 对方开关 | `录制对方声音` | 开 / 关 | `录制对方说话的声音` |
| 我的开关 | `录制我的声音` | 开 / 关 | `使用这台 Mac 的麦克风` |
| 主按钮 | `开始录制` / `停止并保存` | — | `录制画面和所选声音` |
| 状态 | `状态` | 录制中 / 已完成 / 就绪 | — |
| 计时 | `录制时长` | `3 分 42 秒` | — |
| 结果 | `保存结果` | `已保存 FaceTime.mp4，双方声音` | — |
| Finder | `在 Finder 中显示` | — | `打开录音所在文件夹` |
| 菜单 | `更多` | — | `诊断、权限和关于` |

规则：

- 整行开关一个焦点，标题与开关不拆成两个焦点。
- 计时不每秒播报；每 30 秒或聚焦时更新。
- 状态变化播报一次：`录制已开始`、`正在保存`、`已保存`、`录制失败：…`。
- 失败句获得焦点，但焦点不跳走。

### 6.3 视觉

- 正文对比度 ≥ 4.5:1；次要文字用 `#6E6E73`，不用 `#8E8E93` 写正文。
- 录制同时有红点和“录制中”；完成只用文字“已完成”，不依赖绿色。
- 开启 Increase Contrast 时：主按钮改用 `#0066CC`，录制按钮改用 `#D70015`，边框加深。
- Reduce Motion：红点仍静态，开关无动画。
- 36 pt 按钮满足 macOS 最小点击高度；开关整行 48 pt。
