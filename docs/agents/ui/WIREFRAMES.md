# FaceTime Recorder — 极简线框图

版本：2.0 · 日期：2026-11-07 · 对应规范：`UI_SPEC.md`

> 默认窗口 520 × 420 pt，单屏单列。
> `[ON ]` / `[OFF]` 是开关状态；整行可点。
> 图中不画任何技术徽章、路由横幅、电平表、权限矩阵。
> 监听不可选：高级里只有只读 `声音播放：…（系统音量控制）`；画面不列窗口，只显示 `FaceTime 窗口` 或回退后的 `主显示器`。

---

## 0. 容器图例

| 标记 | 层级 | SwiftUI 容器 |
|---|---|---|
| `[1]` | 窗口根 | `VStack(spacing: 0)` |
| `[2]` | 内容列 | `VStack(alignment: .leading, spacing: 0)` + `.padding(.horizontal, 24)` + `.padding(.vertical, 20)` |
| `[3]` | 标题区 | `VStack(alignment: .leading, spacing: 4)` |
| `[4]` | 开关列表 | `VStack(spacing: 8)` |
| `[5]` | 开关行 | 整行 `Button` + `HStack(spacing: 12)`；图标 + `VStack` + `Spacer` + 开关指示 |
| `[6]` | 主按钮 | `Button` + `.frame(maxWidth: .infinity, minHeight: 50)` |
| `[7]` | 状态行 | `HStack`：状态 + `Spacer` + 计时 |
| `[8]` | 结果行 | `HStack`：结果文字 + `Spacer` + Finder 链接 |
| `[9]` | 声明区 | `VStack(alignment: .leading, spacing: 2)` |
| `[10]` | 高级 | `DisclosureGroup` + 内部 `VStack(spacing: 6)` / `Grid` |

规则：

- 没有卡片容器；开关行是唯一的块级元素。
- 没有侧栏、没有右栏、没有滚动主内容。
- 高级展开后允许窗口增高；超过 640 pt 时高级区内部滚动。
- 所有文字左对齐，除了计时和 Finder 链接右对齐。

## 图 1 — 空闲（idle）

```
+----------------------------------------------------------------------+
| FaceTime 录音                                                        |
| 画面 + 声音，一次录好                                                |
|                                                                      |
| +------------------------------------------------------------------+ |
| | [speaker]  录制对方声音                              [ON]        | |
| |            通过 HomePod Flow 虚拟声卡                            | |
| +------------------------------------------------------------------+ |
| +------------------------------------------------------------------+ |
| | [mic]      录制我的麦克风                            [ON]        | |
| |            使用 Mac 默认麦克风                                  | |
| +------------------------------------------------------------------+ |
|                                                                      |
| [                          开始录制                              ]   |
|                                                                      |
| 就绪                                                                 |
|                                                                      |
| 请确保通话对方同意录音。                                             |
| 远端音频：待真人通话验证                                             |
| > 高级                                                               |
+----------------------------------------------------------------------+
```

层级与容器：

1. `[1]` 根 `VStack(spacing: 0)`；标准窗口标题栏，标题 `FaceTime 录音`。
2. `[2]` 内容列：`VStack(alignment: .leading)`，左右 24、上下 20。
3. `[3]` 标题区：`Text("FaceTime 录音")` 24 pt semibold；`Text("画面 + 声音，一次录好")` 13 pt secondary；间距 4。
4. `[3]` 与 `[4]` 间距 20。
5. `[4]` 两个 `[5]` 开关行，间距 8。
6. `[5]` 开关行：整行 `Button`，`HStack`：
   - `Image(systemName: "speaker.wave.2.fill")` 22 pt；
   - `VStack(alignment: .leading, spacing: 2)`：15 pt 标题 + 12 pt 副文案；
   - `Spacer()`；
   - 开关指示（`Toggle` 样式或自绘 switch）。
   - 行高 64，左右内边距 16，圆角 10，1 px 边框。
7. `[5]` 到 `[6]` 间距 18。
8. `[6]` 主按钮：全宽 50 pt 高，红色填充白字，圆角 10。
9. `[6]` 到 `[7]` 间距 12。
10. `[7]` 状态行：左侧 `就绪`，右侧不显示时间；12/13 pt。
11. `[9]` 声明区：同意录音 11 pt secondary；待验证 11 pt tertiary；间距 2。
12. `[10]` 高级：默认收起，11 pt，仅一行 `> 高级`。

空闲重点：

- 两个开关默认都开；整行可点，不是只有开关本体可点。
- 没有权限矩阵、设备选择、监听状态、系统输出说明。
- 没有结果行；完成后才出现。
- 没有顶部待验证徽章；只有底部小字。
- 主按钮是唯一的红色元素。

### 准备中变体（不单独画屏）

点击 `开始录制` 后，仅改三处：

- 状态行：`正在准备…` + 小 spinner。
- 主按钮：`正在准备…`，禁用。
- 两个开关：禁用，保留当前状态。

其余布局不变；不显示步骤列表、不显示自检详情、不显示百分比。

## 图 2 — 录制中（recording）

```
+----------------------------------------------------------------------+
| FaceTime 录音                                                        |
| 画面 + 声音，一次录好                                                |
|                                                                      |
| +------------------------------------------------------------------+ |
| | [speaker]  录制对方声音                              [ON]        | |
| |            通过 HomePod Flow 虚拟声卡              (录制中不可改) | |
| +------------------------------------------------------------------+ |
| +------------------------------------------------------------------+ |
| | [mic]      录制我的麦克风                            [ON]        | |
| |            使用 Mac 默认麦克风                    (录制中不可改) | |
| +------------------------------------------------------------------+ |
|                                                                      |
| [                        停止并保存                              ]   |
|                                                                      |
| * 录制中                                        00:03:42             |
|                                                                      |
| 请确保通话对方同意录音。                                             |
| 远端音频：待真人通话验证                                             |
| > 高级                                                               |
+----------------------------------------------------------------------+
```

层级与容器：

1. 布局与图 1 完全相同，不新增状态卡、不新增电平表。
2. 两个 `[5]` 开关行 `.disabled(true)`；不整体降到不可读透明度；副文案尾部显示 `(录制中不可改)`，11 pt tertiary。
3. `[6]` 主按钮：`停止并保存`，红色填充；点击调用 `stop()`。
4. `[7]` 状态行：8 pt 红点 + `录制中`；右侧 `00:03:42`，13 pt 等宽数字。
5. 不显示远端回调、监听缓冲、路由、设备名、系统输出、采样率。
6. 不显示“FaceTime 已连接”“远端正常”。
7. `[10]` 高级可展开查看只读诊断；展开时窗口增高，不打断录制。

| +------------------------------------------------------------------+ |

| +------------------------------------------------------------------+ |
|                                                                      |
| [                          开始录制                              ]   |
|                                                                      |
| 已完成                                                               |

|                                                                      |

```

层级与容器：

2. `[8]` 结果行：`HStack`：
   - `Text("已保存 FaceTime.mp4（双方声音）")` 13 pt；

   - 只开对方：`（对方声音）`

6. 不自动打开 Finder、不自动播放、不上传。

| +------------------------------------------------------------------+ |
| +------------------------------------------------------------------+ |
| | [mic]      录制我的麦克风                            [ON]        | |
| |            使用 Mac 默认麦克风                                  | |
| +------------------------------------------------------------------+ |
|                                                                      |
| [                            重试                                ]   |
|                                                                      |
| 没有听到对方的声音。请确认 FaceTime 正在通话，                         |
| 并允许系统音频录制。                                                 |
|                                                                      |
| 请确保通话对方同意录音。                                             |
| 远端音频：待真人通话验证                                             |

```

层级与容器：

1. 不显示红色错误横幅、不显示错误卡片、不显示错误编号。
2. `[7]` 状态行替换为一句人话，最多两行；使用 `state.error` 颜色。
3. `[6]` 主按钮：`重试`，红色填充。

5. 失败句只描述“发生了什么 + 下一步”，例如：
   - `没有麦克风权限。请在系统设置中允许，或关闭“录制我的麦克风”。`
   - `没有屏幕录制权限。请在系统设置中允许后重新开始。`
   - `没有听到对方的声音。请确认 FaceTime 正在通话，并允许系统音频录制。`
   - `没有找到 HomePod Flow 虚拟声卡。请确认它已安装。`
   - `已保存原始文件，但 MP4 生成失败。请查看高级 → 诊断。`
6. 技术细节、OSStatus、错误编号只在高级 → 诊断里。

## 图 5 — 高级展开（advanced）

```
+----------------------------------------------------------------------+
| FaceTime 录音                                                        |
| 画面 + 声音，一次录好                                                |
|                                                                      |
| +------------------------------------------------------------------+ |
| | [speaker]  录制对方声音                              [ON]        | |
| |            通过 HomePod Flow 虚拟声卡                            | |
| +------------------------------------------------------------------+ |
| +------------------------------------------------------------------+ |
| | [mic]      录制我的麦克风                            [ON]        | |
| |            使用 Mac 默认麦克风                                  | |
| +------------------------------------------------------------------+ |
|                                                                      |
| [                          开始录制                              ]   |
|                                                                      |
| 就绪                                                                 |
|                                                                      |
| 请确保通话对方同意录音。                                             |
| 远端音频：待真人通话验证                                             |
| v 高级                                                               |
|   远端设备      [HomePod Flow Audio          v]                      |
|   麦克风        [MacBook Pro 麦克风          v]                      |
|   [ON] Apple 回声消除（实验性）                                      |
|   权限  麦克风 ✓   屏幕录制 ✓   系统音频 由自检确认                  |
|   声音播放：MacBook Pro 扬声器（系统音量控制）                       |
|   画面：FaceTime 窗口                                                |
|   开始录制时会把系统声音切到 HomePod Flow，停止后自动恢复。          |
|   [重新自检]   [打开诊断]   [查看日志]                               |
+----------------------------------------------------------------------+
```

层级与容器：

1. `[10]` `DisclosureGroup("高级", isExpanded:)`：
   - 收起：只显示 `> 高级` 一行，11 pt。
   - 展开：显示内部 `VStack(alignment: .leading, spacing: 6)`。
2. 设备行用 `Grid(alignment: .leading, horizontalSpacing: 12, verticalSpacing: 6)`；标签 12 pt secondary，控件 12 pt。
3. AEC：`Toggle` + `实验性` 小字；录制中禁用。
4. 权限：一行紧凑文字；系统音频只能写 `由自检确认`，不能写“已授权”。
5. 声音播放：只读一行，动态显示接管前物理输出设备；不可点击、不可选择、不可调音量。
6. 画面：只读一行，显示 `画面：FaceTime 窗口` 或 `画面：主显示器（未找到 FaceTime 窗口）`；不列窗口。
7. 路由说明：只读一行 11 pt tertiary；不提供接管开关。
8. 操作：`[重新自检]`、`[打开诊断]`、`[查看日志]` 三个小按钮，28 pt 高。
9. 高级展开后窗口可增高到 640 pt；超过后高级区内部滚动。收起回到 520×420。

高级里**不要**出现：

- 录屏开关。
- 监听输出选择器、监听音量滑杆。
- 画面源选择器、窗口列表、显示器选择器。
- 系统输出接管开关。
- 保存位置选择。
- MP4/MKV 文件卡。
- FFmpeg、8ch、tap、aggregate、OSStatus、采样率。
- 电平表、回调数、监听缓冲。
